The one hard problem this ring: the recenter hitch

S1 left a 0.1%-low hitch (77 ms on recenter/spawn). S2-A pooled spawns but a 10-minute flight exposed the recenter itself: translating ~600 body actors back to origin cost 50–90 ms on every shift (measured; FlightVerify pre-fix showed t=51/91/131/151 all 49–61 ms).

Attaching them under one moved scene component did NOT help (parent-move still propagates N child transforms). Fix = one UInstancedStaticMeshComponent: bodies are instances in a GPU buffer stored relative to the component, so a recenter moves that single component and all bodies rebase in one O(1) transform update.
