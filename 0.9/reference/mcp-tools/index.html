    MCP tools¶

    Generated at build from the tool definitions every seat's MCP server advertises (70 tools). A seat sees only its role's bundle; the roles column lists the built-in roles that get each tool (a custom workflow role picks its own in the Design tab).

    artifact · board · close · doc · doctor · framework · identity · knowledge · pool · ruleset · search · thread · ticket

    artifact¶

    artifact_create¶

    Record a produced thing by uri, optionally linked to a ticket. When: you ship something the owner should see. Objects: artifact. Skills: /demo. Enums: form (describe('enums')). Returns the artifact.

    Argument Type Required Meaning
    idempotency_key string
    form one of image, file, url, app, repo_ref yes artifact form
    uri string yes a uri, never a machine path
    note string
    ticket_id string link as produced

    Roles: adversary, architect, engineer

    artifact_read¶

    Read one artifact with its content: an image inline, text inline (6 KB per call). When: a ticket, message or link names it. Objects: artifact. Skills: /demo. Returns the artifact + content; text: next_offset continues via offset.

    Argument Type Required Meaning
    id string yes artifact id
    offset integer

    Roles: adversary, engineer, qa

    artifact_upload¶

    Stage a workspace file (25 MB cap) as an artifact. When: to attach a local file. Objects: artifact. Skills: /demo. Returns the staged artifact; message_send(artifacts=[id]) finalizes it.

    Argument Type Required Meaning
    path string yes workspace file (HTTP policy: absolute, inside configured roots)
    note string

    Roles: adversary, architect, engineer

    board¶

    board¶

    An epic's ticket tree with status counts, ready/in_review lists and open gates. When: for the whole epic at a glance. Objects: ticket, gate. Skills: /ticket, /epic. Returns the board view.

    Argument Type Required Meaning
    epic_id string yes an epic, or any ticket under it

    Roles: architect, doctor, owner, qa

    events_query¶

    Read the event log by subject or since a seq. When: to reconstruct or catch up on events. Objects: event. Returns matching events, a ≤8 KB page from since + last_seq, next_cursor.

    Argument Type Required Meaning
    limit integer
    cursor string
    verbose boolean
    subject_id string
    since integer

    Roles: architect, doctor, owner

    participants¶

    List humans and seats, optionally by role, with @handle and reach. When: to find a collaborator, then message_send(to='@'+handle). Objects: participant. Enums: role, type (describe('enums')). Returns the roster as a ≤8 KB page + next_cursor; verbose=full rows.

    Argument Type Required Meaning
    limit integer
    cursor string
    verbose boolean
    role one of owner, architect, sme, engineer, adversary, qa, doctor
    type one of human, agent

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    close¶

    close¶

    Confirm an epic is closed and get the disarm checklist. When: as the owner, once an epic is done/partial. Objects: ticket, session. Skills: /ticket. Returns the checklist, or a transition error.

    Argument Type Required Meaning
    epic_id string yes epic id

    Roles: owner

    doc¶

    doc_create¶

    Author a versioned markdown doc. When: to record a design, strategy, domain guide, report or note. Objects: doc. Skills: /methodology. Enums: doc_type, status (describe('enums')). Returns the doc; link it to its ticket.

    Argument Type Required Meaning
    idempotency_key string
    doc_type one of design, strategy_hl, strategy_ll, domain, report, note yes design: architect; strategy_*/domain: sme; report: engineer/adversary/qa; note: any
    title string yes doc title
    body_md string yes markdown body
    scope string yes epic id | domain:<name> | global
    tags list of string knowledge tags
    status one of active, proposed proposed: owner approves
    proposes string active doc id it revises
    ticket_id string source ticket

    Roles: adversary, architect, engineer, qa, sme

    doc_edit¶

    Apply exact, unique, non-overlapping edits to one doc version atomically. When: for small revisions after doc_read; match old_text against the original. Objects: doc. Skills: /methodology. Returns a compact receipt, or a conflict/match error (re-read).

    Argument Type Required Meaning
    expected_version integer yes version you read
    edits list of object yes old_text/new_text pairs
    title string
    id string yes doc id

    Roles: adversary, architect, engineer, qa

    doc_query¶

    List docs by doc_type/scope/owner_role. When: to find docs without an id. Objects: doc. Skills: /methodology. Enums: doc_type, owner_role, status (describe('enums')). Returns doc summaries as a ≤8 KB page + next_cursor; verbose=full rows.

    Argument Type Required Meaning
    limit integer
    cursor string
    verbose boolean
    doc_type one of design, strategy_hl, strategy_ll, domain, report, note
    scope string
    owner_role one of owner, architect, sme, engineer, adversary, qa, doctor
    tag string
    status one of active, proposed, retired

    Roles: adversary, architect, doctor, engineer, owner, sme

    doc_read¶

    Read a doc (latest or a version), whole or a bounded range. When: a ticket or link points at a doc. Objects: doc. Skills: /methodology. Returns the doc; offset/limit/section: a version-pinned range.

    Argument Type Required Meaning
    id string yes doc id
    version integer omit for latest; reuse the returned one to continue
    offset integer char offset; opts into bounded output
    limit integer chars, default 8192 when bounded
    section string exact heading line; offset is relative to it

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    doc_update¶

    Replace a doc's body/title as a new version. When: to amend a doc you own. Objects: doc. Skills: /methodology. Returns a receipt; compact=false: the doc.

    Argument Type Required Meaning
    id string yes doc id
    body_md string
    title string
    tags list of string replaces the tag list
    compact boolean

    Roles: adversary, architect, engineer, qa, sme

    link_create¶

    Link from_id to_id (ticket/doc/artifact). When: to attach a design, strategy, evidence, blocker, artifact or doc layer. Objects: link. Enums: relation (describe('enums')). Returns the link.

    Argument Type Required Meaning
    from_id string yes subject (blocks: finishes first; extends: the more specific layer)
    to_id string yes object
    relation one of designed_by, uses_strategy, uses_domain, evidence_for, blocks, produced, extends yes from_id <relation> to_id

    Roles: adversary, architect, engineer, qa, sme

    link_delete¶

    Remove a link. When: to undo a link made in error. Objects: link. Returns whether it was deleted.

    Argument Type Required Meaning
    id string yes link id

    Roles: architect

    link_query¶

    List links by from_id/to_id/relation. When: to see what something is linked to. Objects: link. Enums: relation (describe('enums')). Returns the links as a ≤8 KB page + next_cursor; verbose=full rows.

    Argument Type Required Meaning
    limit integer
    cursor string
    verbose boolean
    from_id string
    to_id string
    relation one of designed_by, uses_strategy, uses_domain, evidence_for, blocks, produced, extends

    Roles: adversary, architect, engineer, sme

    doctor¶

    doctor_dead_mail¶

    Broker publishes that had no recipient (publish_no_route). When: a message that never arrived. Objects: message. Returns the dead messages + causes.

    Roles: doctor

    doctor_feed_lag¶

    Per live seat: unread addressed messages, their age, last request and output. When: a seat that does not answer or wake. Objects: session. Returns seats + causes.

    Roles: doctor

    doctor_health¶

    Service health, the supervisor, package versions and pool reachability. When: first, for any 'it is broken' report. Objects: service. Returns services + causes (named root causes with a fix and a guide).

    Roles: doctor

    doctor_logs¶

    A redacted log tail (secrets, user paths, emails and tokens scrubbed). When: after a health or pool cause names a service. Objects: service. Returns the tail, or the available logs.

    Argument Type Required Meaning
    service string yes board|broker|pool|mcp|bridge|supervisor|update|update-run, or pool-logs/<name>; a wrong name lists the available logs
    lines integer

    Roles: doctor

    doctor_pains¶

    Open pain records (tools or guides found wrong). When: to see whether a symptom is already known. Objects: pain. Skills: /pain. Returns the open pains.

    Roles: doctor

    doctor_pool¶

    Pool liveness, sessions, caps and usage, saturated caps and queued spawns. When: seats not spawning, false deaths, slow spawns. Objects: session. Returns the pool view + causes.

    Roles: doctor

    propose_fix¶

    Propose ONE fix as an admin approval card showing the exact action; nothing runs until an admin approves, then the result is posted on your thread. When: after the evidence names a root cause a listed action fixes. Objects: fix. Returns the proposal and its card.

    Argument Type Required Meaning
    idempotency_key string
    topic_id string yes your help thread (the topic in your context)
    action object yes {kind: service.restart|service.start|service.stop|pool.set_limits|gate.open|gate.answer|teammate.rotate_token|agent_token.revoke, ...its fields}
    effect string yes what the fix will do, in one or two plain sentences

    Roles: doctor

    why_stuck¶

    Why a ticket does not move: gates nobody can answer, a missing checker or doer seat, blockers, the next edges' missing preconditions, a full cap. When: a stuck ticket, epic or gate. Objects: ticket, gate. Skills: /ticket, /epic. Returns the ticket's facts + causes.

    Argument Type Required Meaning
    ticket_id string yes the ticket the person says is stuck

    Roles: doctor

    workflow_check¶

    Validate a workflow version and walk its status graph (unreachable, dead ends). When: a stuck walk under a custom workflow, or a failed update compat check. Objects: workflow. Skills: /epic. Returns problems, walk + causes.

    Argument Type Required Meaning
    ref string yes workflow id or id@version, e.g. standard@1

    Roles: doctor

    framework¶

    harvest_cost¶

    A seat's harvest token cost from its transcript, plus records it wrote. When: at epic acceptance, after the harvest. Objects: cost. Skills: /harvest. Returns window, token totals, record counts.

    Argument Type Required Meaning
    participant_id string yes the seat
    since string
    until string

    Roles: owner, qa

    pain¶

    Pain log: query (q, area, status=all), read (id), file (severity, area, symptom, expected, evidence; dup_of), resolve (id, status). When: a tool or guide is wrong versus reality; query first. Objects: pain. Skills: /pain. Enums: action, severity (describe('enums')). Returns rows or the record.

    Argument Type Required Meaning
    action one of query, file, read, resolve yes what to do
    id string
    q string
    area string
    status string
    severity one of low, medium, high
    symptom string
    expected string
    evidence string
    workaround string
    dup_of string
    supersedes string
    note string
    cursor string

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    service_status¶

    Read-only host services: state, pid, port, git rev, uptime. When: a service seems down; restarting is a human action. Objects: service. Returns one row per service.

    Roles: architect, doctor, owner

    teammate¶

    Owner: teammate credentials: list, create (handle: invite link), mint (handle: token shown once), revoke. When: adding, re-keying or removing a person. Objects: teammate. Enums: action (describe('enums')). Returns the teammate, invite or token.

    Argument Type Required Meaning
    action one of list, create, mint, revoke yes what to do
    handle string
    role string
    admin boolean

    Roles: owner

    workflow¶

    Owner: workflow versions: list, read (ref, full), duplicate (ref), edit|validate (definition), publish (ref). When: changing the workflow an epic pins. Objects: workflow. Skills: /epic. Enums: action (describe('enums')). Returns the version or its problems.

    Argument Type Required Meaning
    action one of list, read, duplicate, edit, validate, publish yes what to do
    ref string
    new_id string
    definition object
    full boolean
    cursor string

    Roles: owner

    identity¶

    context¶

    Load your ticket(s): chain, criteria, docs, thread, open asks; byte-capped unless verbose. When: at boot, after compaction without a cursor, or when a delta says resync_required. Objects: ticket, message. Skills: /ticket. Returns ContextSnapshot with a cursor for context_delta; omitted names each fetch.

    Argument Type Required Meaning
    ticket_id string one ticket, or omit for all yours
    verbose boolean full unbounded snapshot

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    context_delta¶

    Read what changed for you since a context cursor. When: on a heartbeat wake, with your last cursor; not with context() routinely. Objects: event. Returns changes, next_cursor, has_more (byte-capped, omitted names the fetch); resync_required means context().

    Argument Type Required Meaning
    ticket_id string one ticket, or omit for all yours
    cursor string yes the cursor from your last context/delta
    limit integer max changes per page; continue if has_more

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    describe¶

    An object type's fields and contract, or an enum's values ('enums' = all, 'enum:' = one). When: unsure of a type's fields or an argument's allowed values. Objects: enum. Returns the schema and contract, or the enum values.

    Argument Type Required Meaning
    type string yes an object type, 'enums', or 'enum:<Name>'

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    describe_objects¶

    List object/enum names, or one object's schema. When: unsure of an object's contract; omit type to list names. Objects: enum. Returns the index or the schema.

    Argument Type Required Meaning
    type string omit to list; an object name, a Context* type, 'enums' or 'enum:<Name>'

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    get_guide¶

    Fetch one reference guide by name. When: a card or task names a guide. Objects: guide. Returns the guide's markdown, or not_found.

    Argument Type Required Meaning
    name string yes guide name without .md

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    preflight¶

    Host free RAM and live seats vs pool caps; advisory, never blocks. When: before a spawn. Objects: service, session. Returns the numbers and rules of thumb.

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    resume_self¶

    Resume after a park, reap, crash or respawn: re-arm wakes, list open asks and steps. When: first call of a resumed shell, after compaction, or when unsure Monitor/cron are alive. Objects: session. Returns identity, ordered steps, monitor_cmd + cron, open asks; see get_guide('resume').

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    subscribe¶

    Arm your event feed (once per session). When: at boot, right after whoami. Objects: event. Returns the monitor command and heartbeat cron to arm.

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    whoami¶

    Your identity, role, open tickets, lineage and tool bundles. When: at boot. Objects: participant. Returns the participant, tickets, bundles and server version.

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    knowledge¶

    dense_search¶

    Diagnostic: dense-only cosine top-k over an epic's live records. When: diagnosing why lookup missed a record. Objects: decision. Skills: /doubt. Returns hits with cosine scores.

    Argument Type Required Meaning
    scope string yes epic or ticket id
    question string yes plain words
    k integer

    lookup¶

    Current decisions, claims and lessons for a question, id or path in one epic (binding ones always). When: on resume or before acting, instead of trusting memory. Objects: decision, claim, lesson. Skills: /doubt, /learn. Returns records, rendered body and receipt.

    Argument Type Required Meaning
    scope string yes epic or ticket id (never crosses epics)
    question string plain words; or use id/path
    id string record/ticket/doc id to start from
    path string file path to start from

    Roles: adversary, architect, doctor, engineer, owner, qa, sme

    record_claim¶

    Record something stated but not yet shown, with basis and evidence. When: you assert something without attached proof. Objects: claim. Enums: basis (describe('enums')). Returns the claim.

    Argument Type Required Meaning
    idempotency_key string
    scope string yes epic or ticket id
    text string yes one sentence
    basis one of assumption, measured, ruled
    evidence list of string attachment/check/commit ids; a fact needs these plus measured|ruled
    source string message or doc id

    Roles: adversary, architect, engineer, owner, qa, sme

    record_decision¶

    Record what is in force, why, and which decisions it replaces. When: the moment a ruling or in-authority decision is made, before acting on it. Objects: decision. Skills: /doubt. Returns the decision.

    Argument Type Required Meaning
    idempotency_key string
    scope string yes epic or ticket id it is in force for
    text string yes one sentence, <=240 chars
    detail string why, <=1000 chars
    replaces list of string older decision ids it supersedes
    binding boolean true = always handed to seats in scope; omit to inherit
    source string message, doc or attachment id
    domains list of string domain checklist names

    Roles: adversary, architect, engineer, owner, qa, sme

    record_lesson¶

    Record a lesson: domain, topic, one sentence, evidence ids. When: /learn or /harvest. Objects: lesson. Skills: /learn. Returns the lesson.

    Argument Type Required Meaning
    idempotency_key string
    domain string yes domain name
    topic string yes short topic
    text string yes one sentence
    evidence list of string

    Roles: adversary, architect, engineer, qa, sme

    set_binding¶

    Promote or demote a live decision's binding flag (architect/owner); audited. When: re-judging which decisions every seat must follow. Objects: decision. Skills: /doubt. Returns the decision.

    Argument Type Required Meaning
    decision_id string yes a live decision
    binding boolean yes true = binding
    reason string one line, <=240 chars

    Roles: architect

    topic_propose¶

    File a proposed Library doc from a page topic_research fetched; the owner approves it. When: after research, or to propose the next version of a topic doc. Objects: topic, doc. Skills: /methodology. Enums: doc_type (describe('enums')). Returns the proposed doc with Source + fetched-at in its header.

    Argument Type Required Meaning
    idempotency_key string
    topic_id string yes Library topic id
    title string yes doc title
    body_md string yes what you distilled; the board prepends Source + fetched-at
    source_url string yes a URL topic_research fetched
    doc_type one of design, strategy_hl, strategy_ll, domain, report, note
    tags list of string
    proposes string active doc id this is the next version of

    Roles: sme

    topic_research¶

    Search skills.sh or read one page for your Library topic (skills.sh, GitHub, the seed host only). When: a topic seat's research step, before proposing a doc. Objects: topic. Returns search results, or ≤8 KB of page text plus the fetch receipt.

    Argument Type Required Meaning
    topic_id string yes Library topic id
    query string search skills.sh
    url string
    offset integer

    Roles: sme

    withdraw_claim¶

    Withdraw a claim with no successor; lookup never returns it again. When: a claim was superseded or wrong and nothing replaces it. Objects: claim. Returns the withdrawn claim.

    Argument Type Required Meaning
    claim_id string yes claim id
    reason string one line, <=240 chars

    withdraw_decision¶

    Withdraw a decision with no successor; lookup never returns it again. When: a decision was wrong and nothing replaces it. Objects: decision. Skills: /doubt. Returns the withdrawn decision.

    Argument Type Required Meaning
    decision_id string yes decision id
    reason string one line, <=240 chars

    Roles: engineer

    pool¶

    close_self¶

    End your own shell now; refused while inbox is non-empty or no status is recorded. When: step 3 of closing. Objects: session. Returns the release result; then stop calling tools.

    Roles: adversary, doctor, engineer, qa, sme

    inbox¶

    Questions and steers awaiting you, oldest first, each with answer_with. When: first when woken, and step 1 of closing. Objects: message. Returns the list (empty = clear).

    Roles: adversary, architect, doctor, engineer, qa, sme

    reap¶

    Tear down a seat's shell (dead, or the resident architect at epic close). When: to clear a dead seat or close the architect after the epic. Objects: session. Returns confirmation, or running/unavailable.

    Argument Type Required Meaning
    participant_id string yes seat id

    Roles: architect, owner

    record_status¶

    Record your outcome with a one-line note to your spawner, architect and owner. When: at milestones and as step 2 of closing. Objects: message. Enums: status (describe('enums')). Returns the message and who was told.

    Argument Type Required Meaning
    status one of done, deferred, failed, blocked, reviewed, handed_off yes your outcome
    note string one line: done / left
    to string an extra recipient
    ticket_id string omit on a per-ticket seat

    Roles: adversary, architect, doctor, engineer, qa, sme

    resume¶

    Resume a parked or stalled session. When: to wake a stalled seat. Objects: session. Returns the session, or running/unavailable.

    Argument Type Required Meaning
    participant_id string yes seat id

    Roles: architect, owner

    session_query¶

    List sessions by participant/ticket/state. When: to check a seat is live. Objects: session. Enums: state (describe('enums')). Returns matching sessions, newest first, a ≤8 KB page + next_cursor; verbose=full rows.

    Argument Type Required Meaning
    limit integer
    cursor string
    verbose boolean
    participant_id string
    ticket_id string
    state one of alive, stalled, dead, parked

    Roles: architect, owner

    spawn¶

    Start a seat for a role on a ticket. When: to delegate a story/task or spawn a checker. Objects: session, participant. Enums: role, effort, mode (describe('enums')). Returns the session, or status running (poll session_query).

    Argument Type Required Meaning
    role one of architect, sme, engineer, adversary, qa, doctor yes seat role
    ticket_id string registers and assigns '<role>.<ticket_id>'
    participant_id string explicit pool handle; omit with ticket_id
    parent_session string spawning session id
    assign boolean default: only if unassigned/dead; false = checker; true = take over
    model string seat or model id; default: epic tag
    effort one of low, medium, high default: epic tag; Claude caps at medium
    mode one of headless, monitor

    Roles: architect, owner

    ruleset¶

    assemble_ruleset¶

    Compose a ticket's layered ruleset from its strategy/domain docs: enforced lines inlined, each doc one index line. When: at the start of a story/task, for your working brief. Objects: doc. Skills: /methodology. Returns enforced lines + a doc index (full adds constructive), or a cycle/missing-layer error.

    Argument Type Required Meaning
    ticket_id string use its linked strategy/domain docs (inherited up the chain)
    doc_ids list of string explicit leaf doc ids instead
    full boolean also inline constructive lines

    Roles: adversary, engineer, qa, sme

    search¶

    find¶

    Search tickets, criteria, docs and messages by words or meaning; hits carry ticket_id and epic_id. When: to find something without its id. Objects: ticket, doc, message. Skills: /ticket, /methodology. Returns ranked hits with snippets.

    Argument Type Required Meaning
    query string yes words or a phrase (FTS + semantic)
    k integer
    types string comma list of ticket,doc,message,criterion
    epic_id string

    Roles: adversary, architect, doctor, engineer, owner, qa

    thread¶

    gate_answer¶

    Answer an open human gate (owner only). When: to resolve a gate a seat opened. Objects: gate. Skills: /epic. Enums: gate (describe('enums')). Returns the gate_answered event.

    Argument Type Required Meaning
    ticket_id string yes ticket id
    gate one of design_signoff, poc, demo, adversarial, budget, acceptance, scope yes gate kind
    answer string yes the decision

    Roles: owner

    gate_open¶

    Open a human gate on a ticket (one per gate at a time). When: work needs a human decision. Objects: gate. Skills: /epic. Enums: gate (describe('enums')). Returns the gate_opened event; the owner is notified.

    Argument Type Required Meaning
    ticket_id string yes ticket id
    gate one of design_signoff, poc, demo, adversarial, budget, acceptance, scope yes gate kind
    note string the answerer's question, plain words; blank note refused unless the workflow gate declares one
